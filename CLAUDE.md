# Halloween Hackathon — "ВІДПУСТИ" (3D ghost game jam prototype)

Godot 4.7.2 (standard build, **GDScript only**, no C#). Engine lives in `engine/` (portable, `_sc_` = editor settings stay in this folder; `.gdignore` hides it from the project).
Old cooking prototype is backed up in `_archive_cooking/` (ignored by Godot).

## Run
- Editor: `editor.bat` · Game: `play.bat`
- Smoke test (headless, must print `ALL TESTS OK`; if it hangs, an `assert` failed — read the output):
  `engine/Godot_v4.7.2-stable_win64_console.exe --headless --path . res://tests/smoke_test.tscn`
- After editing scripts, run the smoke test. Update it when gameplay rules change.

## Game loop — «Підземелля старого міста»
Story: `docs/comic_script.md` (comic script) + the team's story doc. Тиміш, a servant boy walled up by count Auersberg, forgot who he was. Linear, **no resources, no enemies, no way to lose, one (good) ending**. The ghost floats through every inner wall; only the outer walls stop it.
- **Memories → powers.** A cyan glint (`MEMORY`, only the next one in order is visible) → memory comic → power: 1 Пташка → Подих (candles), 2 Сімнадцятий → Поштовх і звук (noise objects), 3 Лист → Письмо (mirror, writing in the dust), 4 Ключ → Сила рук (knock), 5 Ім'я на стіні (your name). Memory 1 you touch (`E`); 2–4 the ghost can't take: an archaeologist lured next to it with the power in the station's `need` (2 candle `CandleShackles`, 3 noise `Jug`, 4 writing `Dust`) walks up, looks ~3 s (`station.EXAMINE_TIME`) and finds it; the wrong power finds nothing. Memory 5 is no glint: they read your name in your room.
- **Stages** (`GameState.Stage`, driven in `game.gd._process`, visitors react in `visitor.gd`), plan and reasons in `docs/gameplay_plan.md`:
  1. HAUNT «Помітьте мене»: candle on/off, noises, writing → the nearest archaeologist (Олена or Тарас) within 12 m comes to check (`haunt(pos, power, by)`, `visitor.lured_by()`). Memories 1–4, then (the mirror stays locked until Сила рук, or the knock would be impossible later) write ДОПОМОЖІТЬ on the mirror while one is within 7 m → they call the priest.
  2. PRIEST_COMING (15 s, archaeologists talk about «Сімнадцятий, втік») → SEARCH: the time-lapse cutscene (`scripts/timelapse.gd`, `game._search()`; skipped when `comics_enabled` is off): they search, find the plan, clear the collapsed wall `Level/Rubble`; the ghost's cloud trails them.
  3. EVIDENCE: archaeologists look over `game.LOOKS` one by one (shackles, tally, bowl, then the name → memory 5); then knock 3 quick + pause + 1 on `Wall` (west wall at the bunk) with an archaeologist in the room (4 m) → RITUAL: the priest prays 20 s (lines from the finale), hold `E` in the circle (shown only in RITUAL) 2.5 s → finale comic → end screen.
- **Comics** (`scenes/comic.tscn`): two pages in the artist's 6-panel layout. «prologue» plays on the first game start (`GameState.intro_seen`); «memories» panel A–E reveals on memory 1–5, F after the ritual (finale); the same page sits in the J/Tab book. Art/voice/models/textures drop in by file name, see `docs/assets.md`. `game.comic(id)`; the smoke test sets `comics_enabled = false`.
- **3D guide** (`scripts/tour.gd`, `game.tour()`): after the prologue on the first start (and from the pause), a camera flies over the cut-away dungeon (ceiling + world labels culled) through 7 steps with a glowing marker, a pointer pill and a card; Space/→ next, ← back, Esc skip; it ends by diving into the ghost's eyes.
- **Wall flight** (`player.gd`): a sphere query against inner walls / furniture / rubble (`PHASE_MASK`) gives the signed distance to the nearest box → `phase.gdshader` veil + FOV widen; left inside a wall with no input the ghost drifts on (its entry direction, else the nearest side). Pushing into an outer wall frosts the screen edges. Floating into another room shows its name (HUD).
- First person: mouse look, walk 3.5, Shift sprint 6. `Esc` pause, `M` map, `J`/Tab quest + hints book.

## Files
- `scripts/game_state.gd` — autoload `GameState`: phase, `stage` + `set_stage()` + `goal()`, `memories`/`remember(id)`/`name_known()`, `powers`/`has_power()` (`POWERS`, `POWER_NAMES`, `POWER_HELP`, `MEMORY_POWER`, `MEMORY_TITLES`), story flags `mirror_written`, `evidence`, `wall_knocked`, `ritual`, `release_ready()`, `haunt(pos, power, by)` (→ `haunted`). Goal lines in `goal_steps()` are Тиміш's thoughts, the exact action is in the book hints. Signals `memory_found`, `power_gained`, `stage_changed`, `said` (`say()`, `think()`), `hint_unlocked`, `finished`. Book hints `HINTS` + `hint(id)`.
- `scripts/station.gd` — `@tool` interactive object, `kind`: MEMORY (`memory_id`; 2–4 `finder()`), CANDLE (`lit`), HAUNT (need "write" = writing in the dust), MIRROR, PLAN (decor), KNOCK (rhythm), EVIDENCE (`see()`), CIRCLE; `need` = power required (MEMORY: the luring power). `title()` / `can_use()` / `interact(player)`; `witness()` = an archaeologist close enough.
- `scripts/comic.gd` + `scripts/comic_data.gd` + `scenes/comic.tscn` — comic player: `play(id)` → `finished`, pauses the tree; data per id: pages → panels (`text`, `who`, `art`, `voice`, `time`). Test: `tests/comic_test.tscn` prints `COMIC OK`.
- `scripts/ambient.gd` — node `Ambient`, added by `game.gd`: looped air + drone, drips in two rooms, a crackle by lit candles, random one-shots near the ghost, «голос спогаду» (`_callers`: every unfound memory 1–4 calls from its station every 8–12 s, through walls, 25 m, until `memory_found`; own files `audio/memory/memory_<id>.ogg|wav`, else `MEMORY_FALLBACK` = a pitched ambient one-shot); files in `audio/ambient/`, credits in `audio/CREDITS.md`. Test: `tests/ambient_test.tscn` prints `AMBIENT OK`.
- `scripts/easter_eggs.gd` + `scripts/egg_audio.gd` — node `Eggs`: cat (station `Pedestal`, Kind.EGG; first E uncovers it, every next E spins it again), skeleton (station `Bones`, Kind.EGG), rat → turtles' room (shown only after passing through the wall with the rat hole), air-raid alert on the phone (`scripts/air_raid_phone.gd`: lies on `TableR4R`, screen `art/textures/air_raid_phone.jpg`, built in code; close look = close-up overlay); no effect on the story. Hidden in the rock between rooms, visuals on layer 2 (minimap and tour cull it). Test: `tests/eggs_test.tscn` prints `EGGS OK`.
- `scripts/visitor.gd` — archaeologist (ARCH) / priest (PRIEST, hidden until `arrive()`); navmesh walking via `NavigationAgent3D`, behaviour per stage; finds `Markers/*` and `Level/Rubble` through `owner`.
- `scripts/wall.gd` — `@tool` box from `size` (or `art/models/<node name>` via `visual()` / `model()`, textures via `textured()`); `solid_from` 1 = outer wall (blocks the ghost), 2–3 = inner wall / furniture (people + navmesh only); `people_only` = layer 7 (the collapsed wall `Level/Rubble`: a heap of fallen blocks, `art/models/Rubble.tscn`; `tests/rubble_capture.tscn` screenshots it, windowed). `box()`, `holy_glow()`.
- `scripts/player.gd` — first-person ghost: `Head/Camera3D`, aim `RayCast3D` (layer 4) then `Reach` fallback, `E`; collision mask 1. `_sway()` rocks the view while flying (`FLY_*`, `flight`): bob on the head, roll and pitch on the camera. `_aim()` rims the station under the aim (`aim.gdshader` as `material_overlay`), `_wisp()` = the cyan streak on E.
- `scripts/ritual_circle.gd` (Ostap) — the CIRCLE station's model `art/models/Circle.tscn`: PS1-style chalk circle, runes, swirl rings, rays, sparkles, candles (`shaders/psx_*`); grows with `GameState.ritual`, blazes on `release_ready()`. Hidden with its station until RITUAL. Preview: `-s res://tools/circle_preview.gd -- shots <dir>`.
- `scripts/mirror.gd` + `mirror.gdshader` — the MIRROR station's oval glass, a real planar reflection (second camera behind the glass, renders only within `RANGE`); a model with its own box `Glass` (Ostap's) gets a rectangular pane in its place. Ghosts have no reflection: it never sees layer 3.
- Player body: `player.gd` `_build_cloud()` (`cloud.gdshader`), a pale grey-blue cloud shaped like the boy, shown only in the guide (`show_body()`, called by `tour.gd`). In play nothing shows the ghost.
- `tools/cut_comic.py` — cuts a finished comic page into the panel layers + `frame.png`. The prologue is two pages (`prologue` → `prologue2`, key `next` in comic_data). Memories 1, 2, 3, 5 play their own page `memory_N`; memory 4 and the finale have no art yet and play on the `memories` sheet (also the book page).
- `scripts/decor.gd` — corridor dressing from `art/decor/`, hand-placed lists `ON_WALLS`, `ON_FLOOR`, `WEBS` (no collision, not in the navmesh, off the minimap); wall torches get a flame and a light in code. Each model is measured and fitted when placed.
- `scripts/paintings.gd` — node `Paintings`, added by `game.gd`: framed portraits on room walls from `art/paintings/` (list `PICTURES`, no collision) and a looped video painting (`VIDEO`, Theora) with a cubic sound falloff within `HEAR_RANGE`, paused beyond `PLAY_RANGE`. `franko.ogv` was written by Godot's own movie writer (`--write-movie`): frames from ffmpeg's libtheora here decode with broken blocks. Test: `tests/paintings_test.tscn` prints `PAINTINGS OK`.
- `scripts/lanterns.gd` — decoration, `COUNT` small jack-o'-lanterns (`art/models/Lantern.glb`) wandering along the navmesh, one starts next to the ghost; no collision, no gameplay. The navmesh also covers the rock around the rooms: spawn only where `in_dungeon()` says the entrance reaches.
- `scripts/game.gd` — `GameState.reset()` in `_enter_tree` (before the stations build, so a restart starts clean), navmesh bake (`_bake_nav()`, `rebake_nav()`), stage transitions, comics (`comic(id)`), `_search()` → `_open_room()`, `_look_over()` (EVIDENCE), release hold (`at_release()`, `hold`, `_release()`).
- `scripts/map_view.gd` — drawn 2D map (minimap follows the player, M map fits the dungeon): floor from the `rooms` / `doors` metadata the generator writes on the game root, furniture, rubble, doors, lit candles, the next memory, people, your arrow; `ROOM_NAMES`, `room_at()`, `to_map()`.
- `scripts/tour.gd` — the 3D guide (`STEPS`: target node path, camera height / distance, card text, key chips).
- `scripts/timelapse.gd` — «Минають години…» cutscene (replaces PRIEST_COMING / LURE / DIG once wired): `play(game)` → `finished`, `skip()` (Space / Esc). The guide's cut-away top view follows the visitors, tweened along navmesh paths (2 nearest rooms → the PLAN station's room → `Level/Rubble`), 4 `say()` lines, then frees the rubble and rebakes the navmesh. Pauses the tree, hides the HUD (own subtitle line), shows the priest via `arrive()`. Looks like an old film reel (`scripts/film.gdshader`: sepia, flicker, grain, scratches, sprocket strips). Test: `tests/timelapse_test.tscn` prints `TIMELAPSE OK`.
- `scripts/fx.gd` — static feedback kit (`const Fx = preload(...)`): `sound(at, name)` / `sound_ui()` from `audio/sfx/<name>.ogg` (silent when missing), `shake()`, `pop()`, `puff()` dust, `flash()` screen tint, `kick()` camera. Plan for using it: `docs/game_feel_plan.md`.
- `scripts/hud.gd` — all in-game UI built in code (feel: E card pops in, new power icon flies to its slot, stage title card, book pulse on a new goal, knock beat dots) with `scripts/ui.gd` (HUD with powers row + memories counter, goal panel, map, pause, book, end screen); owns `Esc` / `M` / `J`.
- `scripts/ui.gd` + `scripts/paint_box.gd` — hand-painted UI kit (design: Claude Design canvas «ВІДПУСТИ — UI «Мальований»»). Panels, buttons, chips, tags, bars are `paint_box.gd` StyleBoxTextures: 9-slice PNGs from `art/ui/nine/` (Tile Fit, transparent margin = expand margin), picked by colour role (paper / dark / flame / ghost / holy / grey / rust) within a family (`card`, `plate`, `chip`, `key`, `pill`, `tile`, `power`, `bar`, `rule`, or a look name like `book_cover`); setting `bg_color` or calling `use(look)` swaps the texture. Icons `art/ui/icons/` (`UI.icon()`, `UI.power_icon(power, locked|on|new)`), painted titles `UI.painted_title(slug)` from `art/ui/titles/`, textures `art/ui/textures/`. Fonts in `fonts/`: Old Standard TT (labels, buttons), Kurale (body), Marck Script (ghost thoughts, hints). The pack is generated by `python tools/paint_ui.py art/ui fonts art/comic` (slice insets in `art/ui/manifest.json`); power emblems are cut from the memory comic pages.
- `scenes/game.tscn` — **generated** by `python tools/gen_dungeon.py scenes/game.tscn` (rooms as 0.25 m grid rectangles + doors → wall segments, furniture, stations, lights, `Markers` (Entrance, Camp, RoomCenter, dig sites), visitors, player). Edit the generator, not the scene. Keep passages/doors ≥ 1.75 m wide or the navmesh (agent radius 0.5) closes them.
- `tools/painter/` (`paint.bat`) — hand-drawn texture painter.
- `tools/draw_plan.py` draws the plan sheet `art/textures/plan.png` (old architect's drawing from the rooms metadata of `scenes/game.tscn`, your room left off) for `art/models/Plan.tscn` (models from KayKit / Kenney sources live in `art/models/src/`, wrapped by `art/models/<Name>.tscn`); `tools/draw_floor.py` the 1800s cellar flagstone floor `floor.png` + `floor_normal.png` (`textured()` uses `<tex>_normal.png`); `wall.gd` `uneven()` makes the floor dip and swell (visual only). Rerun after the generator changes the rooms.
- `scripts/look.gd` + `look.gdshader` — node `Look` (game.gd): the game's look «Комікс» (Environment overrides `ENV`, light tint/energy folded into `light_color`, screen pass `POST`: ink outlines + cel bands; the shader also has vignette / grain / tint, unused). The pass is a screen-wide CanvasLayer (-2), so it covers any camera, the 3D guide included: keep it that way (the guide's UI sits above it on layer 45, unshaded).
- `scripts/walk_rig.gd` — legacy, unused.

## Collision layers
1 always solid · 2 solid from L2 · 3 solid from L3 · 4 (8) stations (aim) · 5 (16) visitors · 6 (32) invisible floor, navmesh bake only · 7 (64) people-only (rubble). Visual layers: 2 world labels (minimap culls), 3 own ghost body (FP camera culls), 4 ceiling (minimap culls). Visitors mask 1–3 + 7.

## Conventions
- Walls/stations/visitors build their own mesh + shape in code: add a node with the script and set exports (`size`, `solid_from`, `kind`, `title_text`, `min_level`, `color`) in the inspector.
- Scripts reach the box helper via `const Wall = preload("res://scripts/wall.gd")` (no `class_name`: headless runs don't build the class cache).
- UI text is Ukrainian.
- Art is placeholder boxes; swap meshes without touching logic.
