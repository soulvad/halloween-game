# Halloween Hackathon — «Сімнадцятий» (was «ВІДПУСТИ») (3D ghost game jam prototype)

Godot 4.7.2 (standard build, **GDScript only**, no C#). Engine lives in `engine/` (portable, `_sc_` = editor settings stay in this folder; `.gdignore` hides it from the project).
Old cooking prototype is backed up in `_archive_cooking/` (ignored by Godot).

## Run
- Editor: `editor.bat` · Game: `play.bat`
- Smoke test (headless, must print `ALL TESTS OK`; if it hangs, an `assert` failed — read the output):
  `engine/Godot_v4.7.2-stable_win64_console.exe --headless --path . res://tests/smoke_test.tscn`
- After editing scripts, run the smoke test. Update it when gameplay rules change.
- Web build (committed in `builds/web/`, `.gdignore`d): `engine/Godot_v4.7.2-stable_win64_console.exe --headless --path . --export-release "Web" builds/web/index.html` (templates in `engine/editor_data/export_templates/4.7.2.stable/`, web ones only; single-threaded, so any static host works). The web runs the **Compatibility** renderer: no `GeometryInstance3D.transparency` (world labels hide via `labels.gd` `_hide` instead), light limits raised in `project.godot` `[rendering]` (floor/ceiling are one mesh each, 33 lights). Preset "WebTest" (debug, feature `web_test`) runs `tests/web_walk.tscn` as main scene: an autopilot through the whole story with comics on, prints `WALK OK` in the browser console; it goes to `build/webtest/` (git-ignored). Big PNGs and the character textures import as lossy WebP 0.85 (pck ~75 MB).

## Game loop — «Підземелля старого міста»
Story: `docs/comic_script.md` (comic script) + the team's story doc. Тиміш, a servant boy walled up by count Auersberg, forgot who he was. Linear, **no resources, no enemies, no way to lose, one (good) ending**. The ghost floats through every inner wall; only the outer walls stop it.
- **Memories → powers.** A cyan glint (`MEMORY`, only the next one in order is visible) → memory comic → power: 1 Пташка → Подих (candles), 2 Сімнадцятий → Поштовх і звук (noise objects), 3 Лист → Письмо (mirror, writing in the dust), 4 Ключ → Сила рук (knock), 5 Ім'я на стіні (your name). Memory 1 you touch (`E`); 2–4 the ghost can't take: an archaeologist lured next to it with the power in the station's `need` (2 candle `CandleShackles`, 3 noise `Jug`, 4 writing `Dust`) walks up, looks ~3 s (`station.EXAMINE_TIME`) and finds it; the wrong power finds nothing. Memory 5 is no glint: they read your name in your room.
- **Stages** (`GameState.Stage`, driven in `game.gd._process`, visitors react in `visitor.gd`), plan and reasons in `docs/gameplay_plan.md`:
  1. HAUNT «Помітьте мене»: candle on/off, noises, writing → the nearest archaeologist (Олена or Тарас) within 12 m comes to check (`haunt(pos, power, by)`, `visitor.lured_by()`). Memories 1–4, then (the mirror stays locked until Сила рук, or the knock would be impossible later) write ДОПОМОЖІТЬ on the mirror while one is within 7 m → they call the priest.
  2. PRIEST_COMING (15 s, archaeologists talk about «Сімнадцятий, втік») → SEARCH: the time-lapse cutscene (`scripts/timelapse.gd`, `game._search()`; skipped when `comics_enabled` is off): they search, find the plan, clear the collapsed wall `Level/Rubble`; the ghost's cloud trails them.
  3. EVIDENCE: archaeologists look over `game.LOOKS` one by one (shackles, tally, bowl, then the name → memory 5), standing either side of each thing (`visitor._look_spot()`, `focus_side`); the name ТИМІШ comes out scratched on the wall while they read it (`station.scratch()`, `art/textures/name_scratch.png` by `python tools/draw_name.py`); then knock 3 quick + pause + 1 on `Wall` (`station.KNOCK_BEATS`: the first knock starts the beat, each next must land within ±20% of its gap (`knock_window()`), else the attempt restarts with nothing counted; hud.gd draws a target ring on the next dot and a ring shrinking onto it right on the beat) (west wall at the bunk) with an archaeologist in the room (4 m) → RITUAL: the priest prays 20 s (lines from the finale), hold `E` in the circle (shown only in RITUAL) 2.5 s → finale comic → end screen.
- **Comics** (`scenes/comic.tscn`): two pages in the artist's 6-panel layout. «prologue» plays on the first game start (`GameState.intro_seen`); «memories» panel A–E reveals on memory 1–5, F after the ritual (finale); the same page sits in the J/Tab book (`ComicPage.stickers`: panels drawn as stuck-on stickers; keys 1–6 replay a found memory's comic / the finale; the book shows only the latest hint). Art/voice/models/textures drop in by file name, see `docs/assets.md`. `game.comic(id)`; the smoke test sets `comics_enabled = false`.
- **3D guide** (`scripts/tour.gd`, `game.tour()`): after the prologue on the first start (and from the pause), a camera flies over the cut-away dungeon (ceiling + world labels culled) through 7 steps with a glowing marker, a pointer pill and a card; Space/→ next, ← back, Esc skip; it ends by diving into the ghost's eyes.
- **Wall flight** (`player.gd`): a sphere query against inner walls / furniture / rubble (`PHASE_MASK`) gives the signed distance to the nearest box → `phase.gdshader` veil (dark stone haze, the room beyond faint and blurred, a cold rim, a ripple at the surface; hidden while clear) + FOV widen; left inside a wall with no input the ghost drifts on (its entry direction, else the nearest side). Pushing into an outer wall frosts the screen edges. Floating into another room shows its name (HUD).
- First person: mouse look, walk 3.5, Shift sprint 6. `Esc` pause, `M` map, `J`/Tab quest + hints book.

## Files
- `scripts/game_state.gd` — autoload `GameState`: phase, `stage` + `set_stage()` + `goal()`, `memories`/`remember(id)`/`name_known()`, `gain(power)` (game.gd calls it after the memory's comic, so the power comes once the comic is over), `powers`/`has_power()` (`POWERS`, `POWER_NAMES`, `POWER_HELP`, `MEMORY_POWER`, `MEMORY_TITLES`), story flags `mirror_written`, `evidence`, `wall_knocked`, `ritual`, `release_ready()`, `haunt(pos, power, by)` (→ `haunted`). Goal lines in `goal_steps()` are Тиміш's thoughts, the exact action is in the book hints. Signals `memory_found`, `power_gained`, `stage_changed`, `said` (`say()`, `think()`), `hint_unlocked`, `finished`. Book hints `HINTS` + `hint(id)`.
- `scripts/station.gd` — `@tool` interactive object, `kind`: MEMORY (`memory_id`; 2–4 `finder()`), CANDLE (`lit`), HAUNT (need "write" = writing in the dust), MIRROR, PLAN (decor), KNOCK (rhythm), EVIDENCE (`see()`), CIRCLE; `need` = power required (MEMORY: the luring power). `title()` / `can_use()` / `interact(player)`; `witness()` = an archaeologist close enough. A CANDLE stands on `stand` (an `art/decor` model, `stand_turn`), fitted in `_build_stand()` so that its lid (`STAND_LID`) meets the candle's foot: set `stand` and `y` together in the generator, close to a wall, since visitors walk through it. Test: `tests/candles_test.tscn` prints `CANDLES OK` (a ray under every candle, stand clear of walls and decor, flame on top, aim and E); `tests/candle_capture.tscn` screenshots them, windowed.
- `scripts/comic.gd` + `scripts/comic_data.gd` + `scenes/comic.tscn` — comic player: `play(id)` → `finished`, pauses the tree; data per id: pages → panels (`text`, `who`, `art`, `voice`, `time`). Test: `tests/comic_test.tscn` prints `COMIC OK`.
- `scripts/ambient.gd` — node `Ambient`, added by `game.gd`: looped air + drone, drips in two rooms, a crackle by lit candles, random one-shots near the ghost, «голос спогаду» (`_callers`: every unfound memory 1–4 calls from its station every 8–12 s, through walls, 25 m, until `memory_found`; own files `audio/memory/memory_<id>.ogg|wav`, else `MEMORY_FALLBACK` = a pitched ambient one-shot); files in `audio/ambient/`, credits in `audio/CREDITS.md`. Test: `tests/ambient_test.tscn` prints `AMBIENT OK`.
- `scripts/easter_eggs.gd` + `scripts/egg_audio.gd` — node `Eggs`: cat (station `Pedestal`, Kind.EGG; first E uncovers it, every next E spins it again), skeleton (station `Bones`, Kind.EGG), rat → turtles' room (shown only after passing through the wall with the rat hole), air-raid alert on the phone (`scripts/air_raid_phone.gd`: lies on `TableR4R`, screen `art/textures/air_raid_phone.jpg`, built in code; close look = close-up overlay); no effect on the story. Cat and skeleton have sealed rooms of their own (`CatRoom` under your room, `BonesRoom` between Спальня слуг and Комора): no doors, ghost only. Visuals on layer 2 (tour culls it). Test: `tests/eggs_test.tscn` prints `EGGS OK`.
- `scripts/visitor.gd` — archaeologist (ARCH) / priest (PRIEST, hidden until `arrive()`); navmesh walking via `NavigationAgent3D`, behaviour per stage; finds `Markers/*` and `Level/Rubble` through `owner`.
- `scripts/wall.gd` — `@tool` box from `size` (or `art/models/<node name>` via `visual()` / `model()`, textures via `textured()`); `solid_from` 1 = outer wall (blocks the ghost), 2–3 = inner wall / furniture (people + navmesh only); `people_only` = layer 7 (the collapsed wall `Level/Rubble`: a heap of fallen blocks, `art/models/Rubble.tscn`; `tests/rubble_capture.tscn` screenshots it, windowed). `box()`, `holy_glow()`.
- `scripts/player.gd` — first-person ghost: `Head/Camera3D`, aim `RayCast3D` (layer 4) then `Reach` fallback, `E`; collision mask 1. `_sway()` rocks the view while flying (`FLY_*`, `flight`): bob on the head, roll and pitch on the camera. `_aim()` rims the station under the aim (`aim.gdshader` as `material_overlay`), `_wisp()` = the cyan streak on E.
- `scripts/ritual_circle.gd` (Ostap) — the CIRCLE station's model `art/models/Circle.tscn`: PS1-style chalk circle, runes, swirl rings, rays, sparkles, candles (`shaders/psx_*`); grows with `GameState.ritual`, blazes on `release_ready()`. Hidden with its station until RITUAL. Preview: `-s res://tools/circle_preview.gd -- shots <dir>`.
- Dust writing (HAUNT `Dust`): a dust patch on the floor + «ТУТ» traced through it (`art/textures/dust_patch.png` / `dust_writing.png` by `python tools/draw_dust.py`), revealed like the mirror paint (`paint.gdshader`, `gloss` 0); the placeholder box stays, invisible, for the aim rim.
- MIRROR writing: `art/textures/help_writing.png` (finger paint with drips, drawn by `python tools/draw_writing.py`) on a quad over the glass, `scripts/paint.gdshader` smears it on left to right (`reveal`).
- `scripts/mirror.gd` + `mirror.gdshader` — the MIRROR station's oval glass, a real planar reflection (second camera behind the glass, renders only within `RANGE`); a model with its own box `Glass` (Ostap's) gets a rectangular pane in its place. Ghosts have no reflection: it never sees layer 3.
- Player body: `player.gd` `_build_cloud()`: Тиміш's model `art/models/Tymish.glb` in its `idle` clip with a blue rim glow (`ghost.gdshader` as `material_overlay`; without the model, a cloud of `cloud.gdshader` puffs), shown only in the guide and the time-lapse (`show_body()`, which also hides the wall veil). In play nothing shows the ghost.
- Characters (Ostap's, `v4`, picked by soulvad): archaeologists are the rigged 1840s `woman` (Олена) and `young_man` (Тарас) from `art/3d-model/fixed/`, copied to `art/models/src/` and turned to face -Z by `art/models/Olena.tscn` / `Taras.tscn`; the priest (`Priest.glb`) and the ghost (`Tymish.glb`) are ComfyUI models from `art/comfy-models/`, rigged by `tools/rig_character.py` (Blender, from Ostap's `make_tymish.py`: `walker` = idle + walk at visitor.gd's 1.6 m/s, `ghost` = idle, fly, reach, look, release). Sources are `.gdignore`d; `tools/make_priest.py` built the old monk, unused now.
- `tools/cut_comic.py` — cuts a finished comic page into the panel layers + `frame.png`. The prologue is two pages (`prologue` → `prologue2`, key `next` in comic_data). Memories 1–5 and the finale play their own page (`memory_N`, `finale`); the `memories` sheet is the book page. Voice-over script: `docs/voiceover.md`.
- `scripts/decor.gd` — corridor dressing from `art/decor/`, hand-placed lists `ON_WALLS`, `ON_FLOOR`, `WEBS` (no collision, not in the navmesh, off the minimap); wall torches get a flame and a light in code. `_entrance()`: the way in, `art/models/Door.tscn` in a stone frame at the south end of the main corridor (behind the visitors' start), moonlight under it. Each model is measured and fitted when placed.
- `scripts/paintings.gd` — node `Paintings`, added by `game.gd`: framed portraits on room walls from `art/paintings/` (list `PICTURES`, no collision) and a looped video painting (`VIDEO`, Theora) with a cubic sound falloff within `HEAR_RANGE`, paused beyond `PLAY_RANGE`. `franko.ogv` was written by Godot's own movie writer (`--write-movie`): frames from ffmpeg's libtheora here decode with broken blocks. Test: `tests/paintings_test.tscn` prints `PAINTINGS OK`.
- `scripts/lanterns.gd` — decoration, `COUNT` small jack-o'-lanterns (`art/models/Lantern.glb`) wandering along the navmesh, one starts next to the ghost; no collision, no gameplay. The navmesh also covers the sealed rooms: spawn only where `in_dungeon()` says the entrance reaches.
- `scripts/game.gd` — `GameState.reset()` in `_enter_tree` (before the stations build, so a restart starts clean), navmesh bake (`_bake_nav()`, `rebake_nav()`), stage transitions, comics (`comic(id)`), `_search()` → `_open_room()`, `_look_over()` (EVIDENCE), release hold (`at_release()`, `hold`, `_release()`).
- `scripts/map_view.gd` — drawn 2D map (minimap follows the player, M map fits the dungeon): floor from the `rooms` / `doors` metadata the generator writes on the game root, furniture, rubble, doors, lit candles, the next memory, people, your arrow; `ROOM_NAMES`, `room_at()`, `to_map()`.
- `scripts/tour.gd` — the 3D guide (`STEPS`: target node path, camera height / distance, card text, key chips).
- `scripts/timelapse.gd` — «Минають години…» cutscene (replaces PRIEST_COMING / LURE / DIG once wired): `play(game)` → `finished`, `skip()` (Space / Esc). Test: `tests/timelapse_test.tscn` prints `TIMELAPSE OK`.
- `scripts/fx.gd` — static feedback kit (`const Fx = preload(...)`): `sound(at, name)` / `sound_ui()` from `audio/sfx/<name>.ogg` (silent when missing), `tame()` for every 3D sound (`MIX_DB` under, no near-field boost: `NEAR_DB`), `shake()`, `pop()`, `puff()` dust, `flash()` screen tint, `kick()` camera. Plan for using it: `docs/game_feel_plan.md`.
- `scripts/hud.gd` — all in-game UI built in code (end screen: after the finale comic `game._on_finished()` calls `to_be_continued()`: the chalk «Ту бі контіньюд» arrow `art/ui/to_be_continued.png` by `python tools/draw_continued.py` slides in at `END_ARROW_AT` (0:44.5 of the meme video) while `audio/music/end_roundabout.ogg` (Yes «Roundabout» from 0:29, see `audio/CREDITS.md`) plays from the start of the screen; no music while E is held; a click on the arrow opens the credits, `CREDITS` = nicks) (feel: E card pops in, new power icon flies to its slot, stage title card, book pulse on a new goal, knock beat dots) with `scripts/ui.gd` (HUD with powers row + memories counter, goal panel, map, pause, book, end screen); owns `Esc` / `M` / `J`.
- `scripts/ui.gd` + `scripts/paint_box.gd` — hand-painted UI kit (design: Claude Design canvas «ВІДПУСТИ — UI «Мальований»»). Panels, buttons, chips, tags, bars are `paint_box.gd` StyleBoxTextures: 9-slice PNGs from `art/ui/nine/` (Tile Fit, transparent margin = expand margin), picked by colour role (paper / dark / flame / ghost / holy / grey / rust) within a family (`card`, `plate`, `chip`, `key`, `pill`, `tile`, `power`, `bar`, `rule`, or a look name like `book_cover`); setting `bg_color` or calling `use(look)` swaps the texture. Icons `art/ui/icons/` (`UI.icon()`, `UI.power_icon(power, locked|on|new)`), painted titles `UI.painted_title(slug)` from `art/ui/titles/`, textures `art/ui/textures/`. Fonts in `fonts/`: Old Standard TT (labels, buttons), Kurale (body), Marck Script (ghost thoughts, hints). The pack is generated by `python tools/paint_ui.py art/ui fonts art/comic` (slice insets in `art/ui/manifest.json`); power emblems are cut from the memory comic pages.
- `scenes/game.tscn` — **generated** by `python tools/gen_dungeon.py scenes/game.tscn` (rooms as 0.25 m grid rectangles + doors; everything else is solid rock boxes, so room walls are their faces; furniture, stations, lights, `Markers` (Entrance, Camp, RoomCenter, dig sites), visitors, player). Edit the generator, not the scene. Keep passages/doors ≥ 1.75 m wide or the navmesh (agent radius 0.5) closes them.
- `tools/painter/` (`paint.bat`) — hand-drawn texture painter.
- `tools/draw_plan.py` draws the plan sheet `art/textures/plan.png` (old architect's drawing from the rooms metadata of `scenes/game.tscn`, your room left off) for `art/models/Plan.tscn` (models from KayKit / Kenney sources live in `art/models/src/`, wrapped by `art/models/<Name>.tscn`); `tools/draw_floor.py` the 1800s cellar flagstone floor `floor.png` + `floor_normal.png` (`textured()` uses `<tex>_normal.png`); `wall.gd` `uneven()` makes the floor dip and swell (visual only). Rerun after the generator changes the rooms.
- `scripts/labels.gd` — node `Labels` (game.gd, CanvasLayer -1): world labels (Label3D in group `world_label`, kept invisible with `transparency = 1`) drawn flat above the ink pass, which mangled 3D text; first-person camera only, within `visibility_range_end`, hidden behind walls (ray, layers 1–3).
- `scripts/look.gd` + `look.gdshader` — node `Look` (game.gd): the game's look «Комікс» (Environment overrides `ENV`, light tint/energy folded into `light_color`, screen pass `POST`: ink outlines + cel bands; the shader also has vignette / grain / tint, unused). The pass is a screen-wide CanvasLayer (-2), so it covers any camera, the 3D guide included: keep it that way (the guide's UI sits above it on layer 45, unshaded).
- `scripts/walk_rig.gd` — legacy, unused.

## Collision layers
1 always solid · 2 solid from L2 · 3 solid from L3 · 4 (8) stations (aim) · 5 (16) visitors · 6 (32) invisible floor, navmesh bake only · 7 (64) people-only (rubble). Visual layers: 2 world labels (minimap culls), 3 own ghost body (FP camera culls), 4 ceiling (minimap culls). Visitors mask 1–3 + 7.

## Conventions
- Walls/stations/visitors build their own mesh + shape in code: add a node with the script and set exports (`size`, `solid_from`, `kind`, `title_text`, `min_level`, `color`) in the inspector.
- Scripts reach the box helper via `const Wall = preload("res://scripts/wall.gd")` (no `class_name`: headless runs don't build the class cache).
- UI text is Ukrainian.
- Art is placeholder boxes; swap meshes without touching logic.
