# Фінальні асети: куди класти файли

Гра сама підхоплює фінальні малюнки, звук і моделі за **назвою файлу**. Код міняти не треба. Якщо файлу немає, показується заглушка: темна панель, сіра коробка або текст.

> **Після того як додали чи замінили файли**, один раз відкрий `editor.bat` і дочекайся, поки Godot їх імпортує. Потім можна закрити редактор і грати через `play.bat`. Без імпорту гра нових файлів не побачить.

---

## 1. Комікс

У грі **дві сторінки** коміксу, обидві в розкладці художниці на 6 панелей. Порядок читання **A → B → C → D → E → F**, B — висока панель з діагоналями.

```
┌──────┐╲┌─────────┐
│  A   │ ╲│         │
└──────┘  ╲    B    │
┌─────────┐╲        │
│    C    │ ╲       │
└─────────┘  ╲──────┘
┌───┐ ┌─────┐ ┌───┐
│ D │ │  E  │ │ F │
└───┘ └─────┘ └───┘
```

| Сторінка | Папка | Коли показується |
|---|---|---|
| Пролог (передісторія) | `art/comic/prologue/` | на старті гри, усі 6 панелей по черзі |
| Спогади | `art/comic/memories/` | по одній панелі: коли знаходиш спогад, сторінка показується на весь екран, і його панель проявляється. Ця ж сторінка завжди є в книзі (J / Tab) |

**Панелі сторінки «Спогади»:**

| Панель | Що | Коли відкривається |
|---|---|---|
| A | Спогад 1 — Свистулька-пташка | знайдено спогад 1 |
| B | Спогад 2 — Бляха «17» (стук через стіну) | спогад 2 |
| C | Спогад 3 — Лист від матері | спогад 3 |
| D | Спогад 4 — Ключ від хвіртки | спогад 4 |
| E | Спогад 5 — Ім'я на стіні | спогад 5 |
| F | Фінал — Тиміш відпущений | після ритуалу |

Що на пролозі, вирішує художниця. Тексти-заглушки лежать у `scripts/comic_data.gd`.

**Файли:**
- `art/comic/<сторінка>/A.png` … `F.png` — **кожна панель окремим PNG із прозорим фоном, у розмір усієї сторінки**: усе прозоре, крім цієї панелі. Гра накладає їх одна на одну.
- `art/comic/<сторінка>/frame.png` (необов'язково) — рамки й поля поверх панелей.
- Розмір будь-який, головне однаковий для всіх файлів сторінки. Пропорції сторінки гра бере з картинки.
- **Без тексту і підписів на малюнку.** Бульбашки з репліками можна, якщо хочеться.
- Якщо фінальна розкладка відрізняється від ескізу, форми панелей-заглушок і затемнення закритих панелей правляться в одному місці, у `scripts/comic_data.gd`.

## 2. Озвучка коміксу

- `audio/comic/<сторінка>/<панель>.ogg` (можна `.wav` або `.mp3`), наприклад `audio/comic/memories/C.ogg`.
- **Таймінг автоматичний.** Панель триває стільки, скільки звук, плюс 0.4 с, і далі гра переходить до наступної. Щоб задати свій час, вкажи в `scripts/comic_data.gd` для потрібної панелі `"time": 6.5` (секунди).
- Тексти зі сценарію поки показуються як тимчасові субтитри. Коли озвучка готова, їх вимикає налаштування «Субтитри».
- Сценарій озвучки: `docs/comic_script.md`.

## 3. 3D-моделі

`art/models/<Назва>.glb` (або `.gltf`, `.tscn`) замінює сіру коробку об'єкта з такою самою назвою.
- **Одиниці — метри.** Точка опори (origin) — по центру знизу, «перед» дивиться на −Z.
- **Одна модель на групу.** Якщо немає моделі з повною назвою, гра шукає за першим словом: `Candle.glb` піде на всі `CandleHall`, `CandleKitchen`…, `Memory.glb` — на всі спогади, `Crate.glb` — на `CrateR1L` і `CrateR3R`.
- **Зіткнення лишається коробкою**, тож модель має приблизно влазити в її розмір.
- Освітлення, мерехтіння спогадів, свічки й підписи гра додає сама.

| Назва | Що | Розмір коробки (Ш × В × Г, м) |
|---|---|---|
| `Memory1` … `Memory5` / `Memory` | мерехтіння спогаду (свистулька, бляха, лист, ключ, напис) | 0.18 × 0.18 × 0.18 |
| `Candle…` / `Candle` | свічка | 0.12 × 0.3 × 0.12 |
| `Chains`, `Bell`, `Jug`, `Grate`, `Chest`, `Niche`, `GateBell`, `DripChain` | предмети, що шумлять | 0.2–1.0 |
| `Mirror` | запилене дзеркало | 0.1 × 1.4 × 0.9 |
| `Plan` | план маєтку на столі | 0.9 × 0.04 × 0.6 |
| `Door` | двері (відчиняються поворотом) | 1.75 × 2.4 × 0.15 |
| `Wall` | ділянка цегляної стіни, по якій стукають | 0.1 × 2.0 × 1.5 |
| `Shackles`, `Tally`, `Bowl` | речі в твоїй кімнаті (кайдани, подряпини-дні, миска) | 0.1–1.6 |
| `Circle` | коло ритуалу на підлозі | 2.4 × 0.06 × 2.4 |
| `CrateR1L`, `TableR1R`, `BunksR2L`, `BarrelsR2R`, `PlankR3L`, `CrateR3R`, `ShelfR4L`, `TableR4R`, `StonesRT`, `BunkYourRoom` | меблі | див. `tools/gen_dungeon.py` |
| `Olena`, `Taras`, `Priest` | археологиня, археолог, священник (origin біля ніг) | ~0.6 × 1.7 × 0.6 |

## 4. Текстури

`art/textures/` — тайлові PNG, можна малювати в нашій малювалці (`paint.bat`):
- `wall.png` — усі стіни;
- `floor.png` — підлога;
- `ceiling.png` — стеля.

## 5. Пасхалки

**Моделі** в `art/models/`, origin по центру знизу: `Pedestal` (п'єдестал кота, 0.7 × 0.8 × 0.7 м), `Cat`, `Rat`, `Skeleton`, `Bones` (купа кісток), `Turtle` (одна на всіх), `Pizza`. Модель скелета просто гойдається; щоб вона танцювала сама, потрібна окрема анімація в коді.

**Звуки** в `audio/eggs/` (`.ogg`, `.wav` або `.mp3`), без файлу грає згенерована заглушка:
- `cat` — «у і а», грає один раз: кіт крутиться рівно стільки, скільки триває трек;
- `skeleton` — музика для танцю (зациклюється);
- `rat` — писк щура;
- `phone` — сповіщення телефона, не сирена.

Перш ніж класти сюди чужу пісню чи мем, перевірте, чи можна її використовувати: репозиторій здається журі.

## 6. Що ще на заглушках

- Звуки світу й музика: місць під них поки немає.
