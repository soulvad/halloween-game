Візуальні стилі (F7 у грі перемикає)

ВхідТабірДзеркалоКоридорЗамурована стінаТвоя кімната
0. Як зараз
Поточна сцена без змін: рівне фіолетово-сіре ambient, легкий туман.
Вартість: 0 (база)
1. Теплі свічки
Затишно-тривожно, помаранчеве світло факелів, SSAO в кутах, glow на вогнях, віньєтка.
Вартість: низька–середня (SSAO + glow)
2. Холодний туман
Синя сирість, об'ємний туман з ореолами навколо вогнів, приглушені кольори.
Вартість: середня–висока (volumetric fog)
3. Темний хорор
Майже без ambient, тіні від усіх ламп, контраст, зерно плівки, сильна віньєтка. Темні кутки нечитабельні.
Вартість: висока (тіні omni-ламп + SSAO)
4. Комікс
Світліше, насичено, смуги яскравості (cel) + чорнильні контури екранним шейдером. Ближче до коміксових вставок; текстури стін шумлять — потребує пласкіших текстур.
Вартість: низька (один екранний прохід)
5. Зелений привид
Потойбічний зелений туман і світло, glow; найбільш «примарний», але кольори персонажів губляться.
Вартість: середня–висока (volumetric fog)
