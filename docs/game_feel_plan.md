# Чуйний геймплей — план

Кожна дія гравця дає три відгуки: **миттєвий** (звук + ефект на об'єкті, ≤ 0,1 с), **світ** (полум'я, пил, хитання, напис), **люди** (помітили, обернулись, сказали, пішли).

Набір ефектів: `scripts/fx.gd`. Звуки: `audio/sfx/<name>.ogg`, кредити в `audio/CREDITS.md`.

1. **Станції** (`station.gd`): свічка — полум'я гасне з димком / розгорається 0,3 с, «ффух»; шум — предмет хитається, пил, свій звук; письмо — літери проступають по одній, шкрябання; стук — пил, удар, камера здригається, правильний ритм — хвиля; «ще не можу» — глухий тон і думка Тиміша.
2. **Люди** (`visitor.gd`): «?» коли почув, «!» коли знайшов; завмирає й обертається 0,5 с перед тим, як іти; ліхтар повертається до звуку; репліки під дію (свічка / шум / напис).
3. **Привид** (`player.gd`, `hud.gd`): підсвітка предмета під прицілом, картка E з'являється плавно; на E — блакитний струмінь від камери до предмета.
4. **Моменти** (`game.gd`, `hud.gd`): спогад — спалах, сповільнення, шелест; нова сила — значок летить у HUD; титр етапу; ціль — пульс книги.
5. **Мапа** (`map_view.gd`): від шуму розходиться коло, крапки тих, хто почув, блимають.
6. **Ритм стуку** (`hud.gd`): великі кружечки ●●● ● у такт, коли дивишся на стіну для стуку.
